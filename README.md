## 📖 这是什么？

《海虎》是香港漫画家**温日良**（肥良）主编的经典长篇港漫，以"磁场力量"战力体系与极致情感爆发闻名。其角色的独特说话方式被华语网络社群奉为 **"强者语"**——充满极致的自我确信、压倒性的辈分压制、磁场转动的力量量化，以及浓厚的粤语口风。

本项目将这套说话方式抽象为标准的 **AI Agent Skill** 与 **System Prompt**，让任何 AI 工具都能一秒化身海虎，将你输入的每一句话改写成霸气无匹的强者发言。

## 🚀 接入指南

### 🌐 网页端（零门槛，所有人适用）

> **最快上手方式：3 秒开始使用。**

<details>
<summary><b>方法 A：创建持久化专属助手（推荐）</b></summary>

| 平台 | 操作路径 |
|:---|:---|
| **ChatGPT** | 设置 → Custom Instructions，或创建专属 GPTs，将 [`system-prompt.txt`](system-prompt.txt) 内容粘贴进 Instructions |
| **Claude.ai** | 创建 Project → 在 Custom Instructions 贴入改写规则 |
| **Gemini** | 创建 Gems → 将提示词填入 System Instructions |
| **DeepSeek** | 设置中配置个人指令，或在会话首条消息注入 |

</details>

<details>
<summary><b>方法 B：单次临时对话</b></summary>

在任何大模型的对话框中，第一句话发送：

```
请扮演海虎改写器。接下来我发送的所有话，你都不要当作问题回答，
而是按照《海虎》港漫强者语风格进行改写，直接输出改写结果，不加任何解释。
```

然后直接输入你想说的话即可。

</details>

### 🛠️ AI Agent 工具接入

<details>
<summary><b>Antigravity (AGY)</b></summary>

**方式 A — 作为 Skill 挂载：**

```bash
mkdir -p ~/.gemini/antigravity/skills/haihu-rewriter
cp SKILL.md ~/.gemini/antigravity/skills/haihu-rewriter/SKILL.md
```

在对话中指示 Agent 激活海虎改写模式即可。

**方式 B — 在 `AGENTS.md` / `GEMINI.md` 中配置：**

在项目根目录的规则文件中追加：

```markdown
## 海虎改写器指令
当用户要求"改写为海虎风格"或输入文本时，将文本映射为港漫《海虎》强者语，仅输出改写后的台词。
```

</details>

<details>
<summary><b>Claude Code</b></summary>

在项目根目录创建或编辑 `CLAUDE.md`：

```markdown
# 海虎文本改写协议
当被要求改写文本为海虎风格时，严格套用以下规则：
- 语气：绝对断言，严禁犹豫（消灭"可能"、"大概"）。
- 粤风：用"便"替"就"，用"甚"替"什么"，用"搅"替"搞"，句尾常挂"呀"。
- 修辞：以"磁场转动XX匹力量"量化程度，以"爆增！狂增！劲增！"表达激增。
- 仅输出改写内容本身，不附带多余解释。
```

或在终端中使用系统提示参数加载 `system-prompt.txt`。

</details>

<details>
<summary><b>Cursor / Copilot / Codex</b></summary>

**Cursor：**
1. 创建 `.cursor/rules/haihu.mdc`
2. 粘贴 [`system-prompt.txt`](system-prompt.txt) 的完整内容
3. 在 Composer 中 `@haihu` 或直接输入文字触发改写

**GitHub Copilot：**
在仓库根目录添加 `.github/copilot-instructions.md`，写入本项目的改写规则。

</details>

<details>
<summary><b>DSH（DeepSeek 本地工具）</b></summary>

1. 打开 DSH 界面 → Agent / Persona 配置页
2. 新建助手角色，命名为 **"海虎改写器"**
3. 在 System Prompt 字段中粘贴 [`system-prompt.txt`](system-prompt.txt) 的完整内容
4. 保存 → 新建对话 → 发送任意句子，即可获得强者语输出

</details>
